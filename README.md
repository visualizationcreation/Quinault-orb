# Quinault ORB — First encounter

An eight-point narrated learning journey through the connections among rain, forest, water, and the Quinault people. The recorded pilot runs 12 minutes 37 seconds at normal speed.

Open `index.html`, browse the spiral, or begin the guided journey. Narration pauses during exploration and can resume from the parked point. Readings include primary-source links and a copyable Orbiverse continuation prompt. Printing uses the browser's print dialog.

The original Quinault ORB remains available as `original.html`. GitHub Pages publishes the root of the `main` branch. All playback assets use relative paths and are bundled locally.

The 30-, 45-, and 60-minute editions and memory review remain planned. A 69-second forest film study now demonstrates photo media packs and real-time capture. Narration uses Microsoft Aria Neural as a synthetic preview voice; final pronunciation review remains part of production editing. This independent pilot is not an official Quinault Indian Nation or National Park Service publication.
